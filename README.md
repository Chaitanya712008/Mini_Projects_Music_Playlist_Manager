 Music Playlist Manager 

A menu-driven C++ project that manages songs using a **Doubly Linked List**.

Features
- Add and delete songs
- Display playlist forward and backward
- Play current, next, and previous song (console simulation)
- Display the complete playlist
- Repeat the playlist a chosen number of times

 Data Structure
Each song is a node containing its title, artist, and two pointers:
- "next" points to the next song.
- "prev" points to the previous song.

Requirements
- C++ compiler (g++, GCC)
- VS Code or any C++ IDE
